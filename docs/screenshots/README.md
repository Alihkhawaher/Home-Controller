# Screenshots

Screenshots come with the first release.

When they are added, they will follow these rules:

- taken from a release build on a real phone, in both light and dark theme;
- PNG, portrait, at the phone's native resolution, named by screen (`home.png`, `device-climate.png`,
  `automations.png`, `automation-editor.png`, `settings.png`);
- no real IP addresses, MAC addresses, Wi-Fi names or personal names on screen: rename devices and rooms to neutral
  names such as "Living room AC" before taking them.
